# Project Planning

This repository is the central product-engineering workspace for the projects and services running in the network. It records their purpose, direction, relationships, and potential future extensions so that people and agents can reason about the ecosystem as a whole.

It is authoritative for high-level intent, cross-project planning, and long-term direction. Each service repository remains authoritative for its current implementation and is expected to work independently.

This workspace may reference service repositories and their documentation, but it does not aim to duplicate source code, complete API contracts, deployment details, or other implementation-level context.

The workspace is maintained as Markdown and is intended to be used as an Obsidian vault without depending on Obsidian-specific features.

Start with [Home](Home.md) for workspace navigation. The intended organization and note-placement conventions are documented in [Workspace Structure](Workspace%20Structure.md).

## Opening the workspace

In Obsidian, choose **Open folder as vault** and select this repository. Obsidian-specific configuration is kept minimal, while local workspace state and deleted notes are excluded from version control.
